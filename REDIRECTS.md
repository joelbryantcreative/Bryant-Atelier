# Redirects

All rules are **301 (permanent)** and live in `vercel.json`. Both files are generated by `node scripts/redirects.mjs`. Edit the map there, not by hand.

The rules only fire once the old domains point at the new Vercel project:

1. Add `lineagefilms.com.au`, `www.lineagefilms.com.au`, `convertstudios.au` and `www.convertstudios.au` as domains on the Bryant Atelier Vercel project.
2. Update DNS at each registrar (Lineage: GoDaddy; Convert: registrar not recorded) to the records Vercel shows.
3. Remove those domains from the old `Lineage-Films` and `convert-studios` Vercel projects first, or Vercel won't let you add them.
4. Spot-check a few URLs from the tables below with `curl -I`.

Nothing here has been deployed and no DNS has been changed.

## On the new domain

| Request | Goes to |
|---|---|
| `https://www.bryantatelier.com.au/*` | `https://bryantatelier.com.au/*` |
| `/work/we-forest-earth.html` | `/work/` |
| `/work/grun-resort.html` | `/work/` |
| `/work/:slug.html` | `/work/:slug/` |
| `/index.html` | `/` |
| `/public/images/og-image.jpg` | `/assets/og/og-default.jpg` |

Trailing slashes are added automatically (`trailingSlash: true`), so `/work` becomes `/work/`.
